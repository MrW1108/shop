# Wayfarer Supply UI 设计文档

**状态：** 视觉方向已确认（全站霓虹 / 动态网格 / 强动效）
**版本：** 1.0
**依据：** [商品选购 Web 应用 PRD](./PRD.md)
**目标：** 为 50 分钟 React 实作提供清楚、差异化且可落地的界面方向。

> 视觉方向由用户确认。本文为最终 UI 规范；动效采用 CSS 优先实现，并为减少动态效果偏好提供静态版本。

## 1. 设计结论：多品类精选商店，全站霓虹视觉

商店覆盖多个生活/出行品类，以深色全屏舞台、电光紫/青/品红霓虹、动态网格和醒目光效打造未来感。强视觉覆盖首页、导航、品类入口、选中状态、商品卡与购物车；商品照片使用独立高亮底板，文案保持高对比，避免霓虹效果盖住商品和加购信息。

### 已确认方向：Neon Transit / 霓虹跃迁站

将 Wayfarer Supply 做成面向旅途、通勤和日常的多品类装备目的地。首页像一座未来出发终端：扫描网格缓慢流动，光路连接五个商品品类，醒目的装备摄影与霓虹标题构成强舞台感。

**品牌短句**

- EN: `GEAR UP. BREAK OUT.`
- 中文：`装备就位，跃迁出发。`

**首期品类**

- Bags / 包袋
- Travel / 旅行收纳
- Tech / 科技配件
- Drinkware / 饮具
- Everyday Carry / 日常随身

**与常见旅行用品商店的差异化**

- 从单一旅行箱包叙事扩展为多个相关品类的“出发装备站”。
- 用动态网格和发光路线构建独特的整体视觉系统，五个品类成为清晰的目的地入口。
- 品类入口、选中状态和购物车反馈使用不同霓虹色编码，便于用户快速理解状态。
- 商品卡保留名称、价格、评分和加购等高效率信息；装饰光效不覆盖文字或商品主体。

## 3. 视觉系统

### 色彩系统

| 用途 | 色彩 | 使用方式 |
|---|---|---|
| 页面底色 | Void `#070812` | 全站背景和导航栏。 |
| 表面层 | Deep Space `#101224` | 商品信息区、筛选区、购物车与详情面板。 |
| 主文字 | Ice `#F6FAFF` | 深色区域标题、正文和主要价格。 |
| 电光紫 | Plasma Violet `#8A4DFF` | 光晕、边框、焦点和网格节点。 |
| 电光青 | Laser Cyan `#34F5FF` | 链路、搜索焦点、旅行品类标识。 |
| 荧光黄绿 | Acid Lime `#D5FF2F` | 主 CTA、数量徽标、选中状态。 |
| 霓虹品红 | Neon Magenta `#FF3BC8` | Tech/配件类目、选中动画和局部光束。 |
| 商品图底板 | Photo Stage `#F3F4F8` | 商品摄影区，保持真实商品颜色和轮廓清楚。 |
| 辅助文字 | Moon Gray `#B5BED0` | 深色区域的说明、评分数量和次级标签。 |

全站维持深色基底，紫/青/品红用于动态氛围与分类识别，黄绿仅用于最重要的行动和选中状态。霓虹可以大面积出现在背景光场和边框，但不可穿过商品图、长文案或价格数字。

### 字体与图形

- 标题：选择有个性的现代无衬线粗体；优先使用系统字体栈，避免演示依赖远程字体加载。
- 正文：高可读无衬线字体；辅助标签、价格旁信息、登机牌编号可使用等宽字体。
- 圆角：卡片 14–18 px；按钮采用清晰的中等圆角，不做胶囊化全站控件。
- 线条：1 px 深墨低透明度边框；路线虚线、坐标/编号仅用于装饰和分区。
- 图标：使用统一线性图标；若依赖图标库，避免 Emoji 取代功能图标。

## 4. 页面布局与关键状态

### 4.1 商店首页

1. **顶栏**：深色透明底叠加细霓虹底线；左侧 `WAYFARER SUPPLY` 字标带微弱色散光；中部 Bags、Travel、Tech、Drinkware、Everyday 等品类入口；右侧 `EN / 中文`、搜索、购物车和件数。选中品类使用发光短线和颜色标记，手机端保留可见的分类、语言和购物车入口。
2. **主视觉**：首屏全宽深色舞台，叠加低速移动的动态网格、脉冲光环和连接路线。左侧显示 `GEAR UP. BREAK OUT.` 大标题、简短说明和荧光黄绿 `Explore all gear` 按钮；右侧是装备摄影/人物主视觉，配紫青边缘光和 `FIELD KIT 01` 坐标标签。标题使用短暂的遮罩揭示动效；手机端仍先显示标题与 CTA，再显示主图。
3. **品类探索区**：标题 `Choose your portal.` 下方排列五张霓虹品类入口，分别为 Bags、Travel、Tech、Drinkware、Everyday Carry；卡片按品类分配紫/青/品红/黄绿/蓝色光效，带类别图像/图标和 hover/focus 动态轮廓。
4. **商品浏览**：标题 `Selected gear.`；搜索、分类、结果数量与排序位于深色玻璃质感工具条；商品网格覆盖多品类。商品卡使用霓虹边框/光晕与独立浅色商品图底板，文字区留在纯色深底。
5. **精选条/底部信任信息**：加入循环滚动的 `PACK / MOVE / RESET / REPEAT` 霓虹字带，最多三项简短说明，如 USD pricing、Easy returns、Everyday utility，避免虚构真实物流承诺。

### 4.2 商品卡片

- 图像区域占卡片主要面积，使用固定比例和一致裁切；图片放在浅色 Photo Stage 上，与深色信息区形成强烈对比。
- 卡片外框使用暗底和霓虹细边，hover 时发出柔和光晕；顶部小标签使用 `FIELD TESTED`、`PORTAL 02` 等品牌化标识，每卡最多一个。
- 图片下依次展示类别、商品名、评分/评价数、价格与加购动作；名称允许两行，不隐藏价格。
- 桌面端加购按钮始终可见；手机端使用全宽或足够大的按钮，不把加购藏在 hover 中。
- 卡片外框有低频流动渐变；hover 时图片轻微放大、边框亮起；商品卡不做 3D 翻转。

### 4.3 商品详情

- 桌面端为图片与信息并排的对话框/侧面板；手机端接近全屏，内容可滚动。
- 标题区按“类别小标 → 商品名 → 价格/评分 → 短描述”排列。
- 数量控件和主 CTA `Add to bag` 靠近价格区；加入成功后给出简短反馈。
- 背景遮罩、关闭按钮、Esc 关闭均保持清楚；语言切换后商品信息同步切换。

### 4.4 购物车面板

- 桌面端右侧抽屉，宽约 400–460 px；手机端全屏面板。
- 顶部设计成简化的“packing slip”：`YOUR FIELD KIT`、件数、关闭控件；只做视觉处理，不伪造订单或邮寄信息。
- 每行显示缩略图、商品名、单价、数量控件和删除入口；深色面板有扫描线/光边细节，底部固定显示小计及继续购物。
- 可在小计上方显示 `$75` 免运费模拟进度条时，文案需明确这是演示提示。
- 空状态使用小型路线插图/虚线标记和 `Your bag is taking a breather.` 文案，附 `Explore gear` 按钮。

### 4.5 手机适配

- 390 px：主标题、品类入口、语言选择、购物车入口和主要 CTA 易于找到；商品列表建议两列，若名称/按钮拥挤则切换单列。移动设备使用低频/低强度动态背景，确保文本清晰。
- 搜索和分类控件可换行；不压缩到难以点击。
- 商品详情、购物车使用整屏覆盖面板；底部主要操作在可视区域，列表区域单独滚动。
- 360 px 最小支持宽度；避免横向滚动、按钮遮挡、价格换行造成歧义。

## 5. 交互与动效

- **动态网格（常驻）：** 背景网格与紫/青色光场以 12–18 秒周期缓慢流动、轻微呼吸；避免闪烁和高频反差跳变。
- **首屏揭示：** 标题以扫描线/遮罩揭示，主图与路线光轨分层进入；总时长不超过 900 ms。
- **品类传送门：** 品类卡边框有缓慢流动的渐变；hover/focus 时光效加强、图标轻微放大；点击后一道短光线指向商品区。
- **商品卡：** 边缘渐变缓慢流动；hover 时图片轻微放大、卡片上浮 3–4 px、边框亮起。持续动画限制在边框，不影响文字和价格。
- **购物反馈：** 加购时 CTA 发出一次脉冲，购物车徽标弹跳一次，页面顶部出现短暂 `Added to bag` 提示。
- **浮层：** 详情/购物车面板由侧边或底部滑入并带霓虹描边，约 220–300 ms；遮罩淡入。
- **滚动字带：** `PACK / MOVE / RESET / REPEAT` 水平循环滚动，慢速、无突停。
- **搜索与筛选：** 即时更新；过滤结果淡入即可，不使用长距离重排动画。
- **实现边界：** 优先用 CSS transform/opacity/渐变实现，避免 Canvas/WebGL 和大量 blur；控制动画数量，低性能手机仍可滚动和加购。
- **减少动态效果：** 遵循 `prefers-reduced-motion`，关闭常驻网格移动、滚动字带、卡片持续流光和大幅位移，改为静态网格、静态霓虹边框与即时状态切换。

## 6. 英语/中文内容与本地化

- 默认英语，用户可切换简体中文；语言入口显示 `EN` 与 `中文`，桌面和手机端都保留。
- 不只翻译按钮：导航、搜索提示、商品/类别文案、徽标、详情、购物车、空状态、辅助说明和图片替代文本都应双语完整。
- 中文标题可使用自然中文短句，不逐词直译；避免两种语言切换后造成卡片高度明显失衡。
- 价格保持美元：英语 `$24.00`，中文 `US$24.00`；语言切换不得重置搜索、分类或购物车。
- 图标按钮与弹层关闭控件提供当前语言的可访问名称；更新页面 `<html lang>`。

## 7. 可访问性和界面验收

### 设计验收

- [ ] 1440 px 桌面、768 px 平板、390 px 手机下主视觉、商品网格和购物车均有清楚布局。
- [ ] 首页首屏能让用户识别品牌、商品类型、浏览商品入口及语言/购物车入口。
- [ ] 首页有 5 个清楚的品类入口；至少 4 类商品实际出现在商品列表中。
- [ ] 商品卡片无悬停时仍能看见名称、价格和加购操作。
- [ ] 商品详情和购物车浮层有明确关闭方式，手机内容可滚动到底。
- [ ] 360 px 及以上无横向溢出，关键文字不与控件重叠。
- [ ] 霓虹色按钮/标签与背景具备足够对比；长文案不叠放在强光背景上；焦点状态清晰，触控目标建议至少 44 × 44 px。
- [ ] 动态网格、首屏揭示、品类光效和滚动字带工作正常，且不遮挡商品文字、搜索或 CTA。
- [ ] 开启减少动态效果后，所有常驻运动和大幅位移动画关闭，静态视觉仍完整。
- [ ] 英语/中文文案均完成，无关键区域中英混排；切换语言后商品列表和购物车状态一致。
- [ ] 图片失败时保留固定占位区域，不破坏页面高度和卡片结构。
- [ ] 视觉识别符号是装饰，不会被误认为筛选器、行程信息或真实承诺。

### 实作优先级

- **必须落地：** 全站霓虹色彩系统、至少一层动态网格背景、主视觉揭示、响应式品类入口、商品网格、搜索/分类、双语切换、详情、加购、购物车面板、空状态和减少动态模式。
- **有余力再做：** 卡片连续流光、品类点击光线路径、购物车扫描线、第二张商品图、保存语言偏好。
- **不建议在 50 分钟内做：** WebGL/3D 场景、复杂地图、视频背景、长篇滚动叙事和多个商品详情路由。

## 8. 已确认的设计决策

- **已确认：** 全站霓虹视觉、动态网格、强动效。
- **品类：** Bags、Travel、Tech、Drinkware、Everyday Carry 五个一级类目。
- **色彩：** Void 深色底，Plasma Violet / Laser Cyan / Neon Magenta 光效，Acid Lime 作为主行动色。
- **语言：** 英语默认、简体中文可切换；金额统一显示美元。
- **体验底线：** 商品图/价格/CTA 清晰可读；强动效需提供 `prefers-reduced-motion` 静态模式。
